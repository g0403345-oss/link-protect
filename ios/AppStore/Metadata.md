## Description
Link Protect is the companion app for the Link Protect Discord bot. Sign in with
Discord and manage every server you administer from one place:

• Link blockers — toggle protection for NSFW, Nitro scams, malware/phishing,
  invites, YouTube, Google, GIFs, Twitch, Steam, URL shorteners, or block all
  links at once.
• Warning system — set kick, ban, and timeout thresholds and review warned users.
• Access control — whitelist channels, categories, members, or roles.
• Custom blacklist — block specific domains.
• Statistics — see warnings issued and your most-warned users.
• Live activity log — watch moderation actions stream in, in real time.
• Push notifications — get alerted when the bot goes offline, a protection rule
  is triggered, or a server's settings change.

Link Protect signs you in with Discord only. We request just the `identify` and
`guilds` scopes and never store your messages or personal data.

Requires a Discord account and the Link Protect bot installed on a server you
manage (you need the "Manage Server" permission).
